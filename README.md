# FOAF — Friend of a Friend

**A mirror. Not maintained by Ontoshire.**

Published by Dan Brickley and Libby Miller. This repository contains **no RDF** — only an `ontoshire.ttl`
naming the publisher's own canonical URL, which Ontoshire fetches unchanged
when a version is published.

| | |
|---|---|
| Source | <https://xmlns.com/foaf/spec/index.rdf> |
| Ontology IRI | `http://xmlns.com/foaf/0.1/` |
| Licence | [CC BY 1.0](https://creativecommons.org/licenses/by/1.0/) |

Mirrored so the ontology is discoverable alongside others. The bytes are
always the publisher's, and the published version records a checksum of
exactly what was fetched.

The IRI mirrored here is the one ontologies actually import — `http://xmlns.com/foaf/0.1/` — so an `owl:imports` of FOAF resolves to this copy. Ontoshire's own publishing quickstart uses exactly that import in its worked example.

If you maintain this ontology and would rather it were not mirrored here,
[tell us](mailto:enquiries@ontoshire.com) and it will be removed.
